Quick Start Installation

Setup Virtual Environment

python -m venv .venv && source .venv/bin/activate

Creates isolated Python environment for dependency management

Install Dependencies

pip install -r requirements.txt

Installs pytest, pytest-cov, python-dotenv, ruff, mypy

Configure Environment

cp .env.example .env

Copy example environment variables for local development

Testing & Quality Assurance

Run Full Test Suite

pytest --cov=. --cov-report=term-missing --cov-fail-under=70

Execute all tests with 70% minimum coverage enforcement

Code Linting

ruff check .

Static analysis with Ruff for code quality

Type Checking

mypy . --ignore-missing-imports

Type safety verification with MyPy
