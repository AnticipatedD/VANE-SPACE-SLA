# VANE-SPACE-SLA Architecture & Infrastructure

## Overview
VANE-SPACE-SLA provides simulated telemetry validation, M2M OAuth gateway capabilities, and prompt grounding toolkits.

## Infrastructure & Deployment
- **Terraform**: Located under `terraform/` for infrastructure state orchestration.
- **Docker**: Containerized deployment via `docker-compose.yml` and `Dockerfile`.
- **CI/CD**: GitHub Actions workflows in `.github/workflows/`.
